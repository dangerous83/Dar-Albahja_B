# Dar Albahja · Marrakech — Brand Identity Story

An interactive, 40-page storytelling presentation of the Dar Albahja logo and brand identity.

## The experience

1. **The Door (page 1)** — a password gate. The key is `dena`.
2. **Act I — The City (2–9)** — Marrakech, the tagine, eight-fold geometry, the colours and the brief. The logo is never shown.
3. **Act II — The Hand (10–16)** — sketches, construction and refinement boards (final-logo previews stay covered).
4. **Act III — The Assembly (17–19)** — an interactive puzzle: the audience must assemble the emblem to unlock the reveal.
5. **Act IV — The Identity (20–31)** — lockups, monochrome, mood boards, palette, colourways, typography.
6. **Act V — Into the World (32–39)** — stationery, packaging, uniform, signage, events, and a responsive website preview (desktop / tablet / phone).
7. **Shukran (40)** — finale.

## Features

- Keyboard (←/→/space), mouse wheel, touch-swipe and on-screen navigation
- Auto-play mode (▶) that pauses at the interactive gates
- Chapter menu with lock-aware jumping, progress bar and page counter
- Drag-and-drop **and** tap-to-place logo assembly puzzle (mobile friendly)
- Copy-to-clipboard palette, hotspot emblem anatomy, live type specimen
- Friendly WebAudio sound effects (toggle with the 🔊 button)
- Numbered puzzle tiles and cells for easy assembly
- Downloadable full-presentation PDF on the last page — encrypted, opens with the same key `dena`
- Fully responsive; progress persists per session

## Hosting

Pure static site — `index.html` plus the `web/` folder (optimized images derived
from the original artwork files in the repo root). Enable GitHub Pages on this
branch (or merge to `main`) and it works as-is.
